# 直击先进案例库

> 走进企业真实业务现场，沉淀可复用的 AI 与数字化实践。

「直击先进」是一档面向企业数字化实践者的案例直播栏目：每期走进一家先锋企业，对话一线操盘手，把 AI 落地、组织转型、数字化提效的真实经验沉淀为可复用的案例库。本仓库是该案例库的网站化产物。

## ✨ 功能特性

- **先锋实录**：71 期案例库，支持「按行业找案例」「按岗位找案例」双 Tab 切换，快速定位同行业 / 同岗位的实践
- **素材检索**：按期数检索案例素材，支持企业 / 行业 / 形式 / 回放 / 大礼包多维筛选
- **直播回放**：案例卡片一键跳转飞书社区回放；大礼包、报名链接直达
- **本地离线可用**：整个站点为单文件 HTML（含全部数据与资源引用），下载后双击即可打开

## 🔄 更新与部署

本仓库通过 GitHub Pages 自动部署（source: main 分支根目录）：

```bash

git add index.html
git commit -m "更新内容"
git push origin main
```

推送后约 1 分钟，网站自动生效。
