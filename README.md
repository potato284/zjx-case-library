# 直击先进案例库

> 走进企业真实业务现场，沉淀可复用的 AI 与数字化实践。

一个面向企业数字化实践者的案例库站点，聚合各行业先锋企业的 AI 落地案例、直播回放与可复用素材，帮助读者学习先进数字化实践。

## 🔗 在线访问

**网站地址：https://potato284.github.io/zjx-case-library/**

由 GitHub Pages 免费托管，永久可访问，无需登录。

## ✨ 功能特性

- **首页**：案例库概览、数据总览（期数 / 行业 / 累计观看）、近期直播推荐
- **先锋实录**：71 期直播案例库，支持「按行业找案例」与「按岗位找案例」双 Tab 切换，覆盖 9+ 行业、多种岗位视角
- **素材检索**：按期数检索案例素材，支持企业 / 行业 / 形式 / 回放 / 大礼包多维筛选
- **直播回放**：案例卡片直接跳转飞书社区回放，大礼包、报名链接一键直达
- **本地离线可用**：整个站点为单文件 HTML（含全部数据与资源引用），下载后双击即可打开

## 🔄 更新与部署

本仓库通过 GitHub Pages 自动部署（source: main 分支根目录）：

```bash
# 修改本地 index.html 后
git add index.html
git commit -m "更新内容"
git push origin main
```

推送后约 1 分钟，网站自动生效。

## 🛠 技术栈

- 纯前端单页应用（原生 HTML + CSS + JavaScript，hash 路由）
- 数据内嵌于 HTML（飞书多维表格导出快照，离职前固化）
- 图片 / 音频资源经压缩后托管于 CDN，页面通过 URL 映射引用
